# 오늘의 필름 — 프론트엔드 전체 버튼·기능 인벤토리 (ver0)

프론트(`ver0/frontend/lib`) + 백엔드(`ver0/backend/app`) 대조. **이미 구현된 것도 모두 포함.**

**상태 범례**
- ✅ **완결** — UI 있고 백엔드 API까지 연동됨
- 🟡 **UI만/스텁** — 버튼은 있으나 동작 미완, 로컬 전용, 또는 "준비 중"
- ⬜ **미구현** — 백엔드 API는 있는데 프론트에 화면/버튼 없음

핵심 플로우: **로그인 → 사진 선택(STEP01) → AI 질문·답변(STEP02) → 필름 생성(STEP03) → 아카이브/마이**

---

## 3. 사진 선택 — STEP01 (photo_select_screen)

| 버튼·기능 | 상태 | API |

## 한눈에 보기 — 상태별 집계

**🟡 UI만/스텁 — "동작만 붙이면 되는" 것 (우선순위 높음)**
- 필름 카드 공유하기(버튼만 비어있음) → `/records/{id}/share`
- 내 필름 내보내기("준비 중") → `/auth/me/export`
- 저녁 알림(로컬만) → `/auth/me/settings`
- 필름 스타일(로컬만, 백엔드 필드 없음 — 정책 결정 필요)
- 데모 모드(백엔드 미연동)

**⬜ 미구현 — 백엔드는 있으나 프론트에 없음**
- *핵심 UX*: 답변 수정, 필름 결과 수정(제목·내레이션·기억문장), 기록 삭제, `safety_notice` 배너, recall 카드, 기억 연결 카드, "다시 꺼내지 않기"
- *차별화*: 과거의 오늘, 키워드 검색, 순간 기록(추가·목록·삭제), 음성 답변, 월간·연간 리포트(화면 신설), 위치·날씨 첨부
- *설정·개인정보*: 마이 통계 표시, 닉네임 수정, 회상 on/off

**✅ 이미 완결**
- 회원가입·로그인·자동로그인, 사진 업로드·기록 생성, 질문 받기/다시받기/답변/건너뛰기, 필름 생성, 월간 캘린더·기록 상세, 계정 삭제, 로그아웃

> 현재 `api_service.dart` 연결 메서드: signup·login·me·myStats·deleteAccount·uploadPhotos·createRecord·nextQuestion·submitAnswer·generateFilm·monthCalendar·recordDetail
